The template started as a fork of [Rover Resume](https://github.com/subidit/rover-resume), and was then customized in structure and style.

## Getting Started

To get the files on your computer, just clone this repository:

1. Choose where you want to store the files in your terminal

   ```bash
   cd Projects/resume
   ```

2. Clone the repository

   ```bash
   git clone https://github.com/EmanueleSeminara/LaTeX_resume.git
   ```

After that, you only need to edit the content of the files to write what you want in your resume.
It is really simple: the comments at the beginning of the `.tex` file explain the custom commands used by the template.

## Compilation

The template is made for **pdfLaTeX** and uses `fontenc` with T1 encoding: this is needed so that accented letters are
extracted correctly from the PDF, which matters for the ATS systems that read resumes automatically.

To compile locally you need a LaTeX distribution available in your system PATH. On macOS you can install
[MacTeX](https://www.tug.org/mactex/mactex-download.html), downloading `MacTeX.pkg` from the download page.
For other operating systems, or for lighter alternatives, see the
[TeX Live documentation](https://www.tug.org/texlive/).

If you use Visual Studio Code, the [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)
extension handles the compilation automatically once the distribution is installed.

Otherwise, if you do not want to install anything, you can use [Overleaf](https://overleaf.com): a free online editor,
just create an account, start a new project and upload the files of this repository.
